🔐 Secrets vault

Store API keys here when Netlify's env var space is full. They're saved in your private Xano app_config table and read by functions at runtime — no 4KB limit, no redeploy. Owner-only — not the office password.

First time only: in Xano, add a table named app_config with two text columns name and value (don't add any API endpoints to it — that keeps it private). Then come back here and save your key.
