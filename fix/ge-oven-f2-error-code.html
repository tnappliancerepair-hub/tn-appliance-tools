What does the F2 error code mean on my GE oven or range?

F2 on a GE oven or range means the control saw the oven get hotter than it should and shut the heat down to protect itself. It's a safety code, and it usually points at one of two things: a relay on the control board that stuck "on," or an oven temperature sensor that's reading wrong. Here's the order a tech works it.

⚠ Safety first: ⚠️ An over-temp code means the oven ran too hot — good that it shut down. Let the oven cool fully before anything. Oven elements and controls run on 240V; sensor/control replacement is done by a tech with the power off at the breaker.

The most likely causes

Drifted or failing oven temperature sensor Moderate DIY check

The oven sensor tells the control how hot it is. If it drifts out of spec, the control can misread the temperature and throw F2. It's the cheaper, more common of the two causes.

Check it: A tech ohms the sensor against spec — an affordable part if it's reading wrong. Try a check: unplug the oven for a minute to clear the code; if F2 returns during heating, have the sensor tested.

Stuck (welded) relay on the control board Technician

The control has relays that switch the bake/broil elements on and off. If one welds "on," the element keeps heating past the setpoint, the oven overheats, and F2 trips. This is the cause you don't want to ignore — a stuck-on element is why the oven ran away.

Check it: This is a tech diagnosis — if the sensor tests good but the oven overheats, the control board with the stuck relay needs replacing.

Control board fault Technician

The electronic control (often called the EOC) itself can fault and misfire the heat circuit, showing F2.

Check it: A tech confirms whether it's the sensor vs the control and replaces the failed one.

Is it worth fixing?

Repair — the oven sensor is a cheap part, and even a control board is well below a new range. F2 is worth fixing, and worth NOT ignoring, since a stuck-on element is a safety issue.

Common questions

What does F2 mean on a GE oven?

It's an over-temperature code — the oven got hotter than it should and shut off to protect itself. The usual causes are a drifted oven temperature sensor (cheaper) or a stuck relay on the control board (why it overheated).

Can I fix a GE oven F2 code myself?

You can unplug the oven for a minute to clear the code and see if it returns, but the actual fix — testing/replacing the oven sensor or a control board with a stuck relay — is a tech job on 240V. Don't keep using an oven that overheats.

Is a GE oven F2 code dangerous?

The code itself is the oven protecting you, but the common cause (a stuck-on heating relay) means the oven ran away hot — worth fixing promptly. Your $50 Quick Check credits toward the repair.
