What does the F10 code mean on my Frigidaire oven?

F10 on a Frigidaire oven (also common on Kenmore-badged Frigidaire) is a runaway-temperature alarm — the control read a temperature that was too high or out of range and shut the oven off to protect it. That's a safety trip, not always a broken part, but it needs to be pinned down before you keep cooking with it. Here's how a tech works it.

⚠ Safety first: Treat a runaway-temp code seriously. Stop using the oven until it's diagnosed — if the control relay ever sticks closed, the element can stay on. The sensor check and any board work should be done with the range unplugged.

The most likely causes

Drifted or shorted oven temperature sensor (RTD) Technician

The #1 cause. The oven sensor tells the control the real temperature; when it drifts out of spec or shorts, the control reads a false high temp and trips F10.

Check it: With the oven cool and unplugged, a tech checks the sensor's resistance (about 1080 ohms at room temperature). Off-spec = replace the sensor, an affordable common part.

Try a reset first Easy DIY check

A momentary glitch can trip a one-off F10.

Check it: Unplug the range (or flip its breaker) for 5 minutes and restore power. If F10 stays gone through a normal bake, it was a glitch. If it returns, move to the sensor.

Stuck control (EOC) relay Technician

The next cause: a relay on the electronic oven control sticks, so the element stays powered and the temperature truly runs away.

Check it: If the sensor is in spec but F10 returns, a tech tests the oven control board (EOC) — a stuck bake/broil relay is the classic finding.

Sensor wiring Technician

A pinched or corroded wire between the sensor and the control mimics a bad sensor.

Check it: A tech inspects the sensor harness at the back of the oven during the sensor check.

Is it worth fixing?

Usually repair — an oven sensor is an inexpensive, common part with flat labor. Even a control board (EOC) is well below a new range on most models. Because F10 is a safety trip, get it diagnosed rather than ignored.

Common questions

How do I fix the F10 code on my Frigidaire oven?

First reset it — unplug the range (or flip the breaker) for 5 minutes and restore power. If F10 comes back, the most common fix is the oven temperature sensor (RTD), which reads out of spec; next is a stuck relay on the oven control board. Both are affordable, common repairs — but stop using the oven until it's diagnosed since F10 is a runaway-temp safety trip.

Is it safe to use my oven with an F10 code?

No — F10 means the control shut the oven off because it saw a runaway temperature. Leave it off until a tech confirms whether it's just the sensor or a stuck relay that could keep the element powered.
