What does the F30 or F31 code mean on my Frigidaire oven?

F30 (open) and F31 (shorted) on a Frigidaire oven both point straight at the oven temperature sensor circuit — the control can't read a valid temperature from it, so it won't heat correctly and throws the code. It's one of the most repairable oven codes there is, because the part is cheap and common. Here's the order a tech works it.

⚠ Safety first: Low-risk to reset. The sensor and wiring check should be done with the range unplugged — there's line voltage in the oven control area.

The most likely causes

Oven temperature sensor (RTD) failed Technician

The main cause of both codes. F30 = the sensor circuit reads open (broken); F31 = it reads shorted. Either way the sensor or its circuit is out of spec.

Check it: With the oven cool and unplugged, a tech checks the sensor resistance (about 1080 ohms at room temp). An open, shorted, or off-spec reading = replace the sensor — an inexpensive, common part.

Loose or corroded sensor connector Technician

The sensor plugs into the wiring at the back of the oven cavity; a connector that's worked loose or corroded reads exactly like an open sensor (F30).

Check it: A tech reseats and inspects the sensor connector — sometimes that alone clears F30, no part needed.

Pinched or damaged sensor wire Technician

A wire pinched behind the oven or melted near heat can open (F30) or short (F31) the circuit.

Check it: A tech inspects the sensor harness for damage during the sensor check.

Control board Technician

Least common — the control misreads a good sensor circuit.

Check it: If the sensor and wiring test good but F30/F31 stays, a tech tests the oven control board.

Is it worth fixing?

Repair — an oven temperature sensor is one of the cheapest, most common oven parts, with flat labor well below a new range. F30/F31 is a very fixable code.

Common questions

How do I fix the F30 code on my Frigidaire oven?

F30 means the oven temperature sensor circuit reads open. First a tech reseats the sensor connector at the back of the oven — sometimes that clears it. If not, the sensor itself is out of spec and gets replaced, an inexpensive common part.

What's the difference between F30 and F31 on a Frigidaire oven?

Both are oven-sensor faults: F30 means the sensor circuit reads open (broken/disconnected), F31 means it reads shorted. Same part, same fix — replace the oven temperature sensor after confirming the wiring.
