What does the E101 code mean on my Bosch oven?

E101 on a Bosch oven points at the oven temperature sensor — the NTC probe that tells the control how hot the oven is. When it reads open, shorted, or out of range, the control can't trust the temperature, so it won't heat correctly and throws E101. It's one of the more repairable Bosch oven codes because the sensor is an affordable, common part. Here's the order a tech works it.

⚠ Safety first: Low-risk to reset. The sensor and wiring check should be done with the range unplugged — there's line voltage in the oven control area.

The most likely causes

Oven temperature sensor (NTC) failed Technician

The main cause. The NTC sensor drifts out of spec, opens, or shorts, so the control reads an invalid temperature and flags E101.

Check it: With the oven cool and unplugged, a tech checks the sensor's resistance against spec and inspects it. Out-of-range = replace the sensor, an affordable common part.

Try a reset first Easy DIY check

A momentary glitch can trip a one-off E101.

Check it: Unplug the range (or flip its breaker) for 5 minutes and restore power. If E101 stays gone through a normal bake, it was a glitch. If it returns, move to the sensor.

Sensor connector or wiring Technician

A loose or corroded connector at the sensor, or a damaged wire, reads exactly like a failed sensor.

Check it: A tech reseats and inspects the sensor connector and harness during the sensor check — sometimes that alone clears E101.

Control board Technician

Least common — the control misreads a good sensor circuit.

Check it: If the sensor and wiring test good but E101 stays, a tech tests the oven control board.

Is it worth fixing?

Repair — an oven temperature sensor is one of the more affordable oven parts, with flat labor well below a new oven. E101 is a very fixable code.

Common questions

How do I fix the E101 code on my Bosch oven?

First reset it — unplug the range (or flip the breaker) for 5 minutes. If E101 comes back, the fix is almost always the oven temperature sensor (NTC), which reads out of range; a tech checks the sensor and its connector and replaces the sensor, an affordable common part.

What does E101 mean on a Bosch oven?

It's an oven temperature sensor (NTC) fault — the sensor reads open, shorted, or out of range, so the control can't trust the temperature and won't heat right. Usually the sensor itself; sometimes a loose connector.
