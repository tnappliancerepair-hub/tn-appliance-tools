What does the F5E2 error code mean on my Whirlpool washer?

F5E2 on a Whirlpool top-load washer means the lid lock isn't locking — and a top-loader won't spin or run its cycle until it confirms the lid is locked. So the machine stops and flags F5E2. It's a specific, well-defined fault, and a couple of causes you can check yourself. Here's how a tech works it.

⚠ Safety first: Low-risk. Unplug the washer before checking or handling the lid-lock mechanism.

The most likely causes

Something blocking the lid from seating Easy DIY check

The simplest cause: laundry, a stray item, or buildup keeps the lid from closing fully onto the striker, so the lock can't engage.

Check it: Make sure the lid closes fully with nothing under it, and that the strike area is clean. Push the lid firmly down and restart.

Failed lid-lock assembly Moderate DIY check

The most common real cause. The lid-lock mechanism has a small motor/solenoid and switches that wear out, so it can't lock (or can't confirm it locked).

Check it: Listen for the lock trying to click when a cycle starts. A lock that's silent or clicks but never confirms is an affordable, common tech replacement.

Wiring / connector to the lock Technician

A loose or corroded connector between the lock and the control can break the signal, so the control never sees the lid lock.

Check it: A tech checks the lock's wiring and connector while testing the assembly.

Control board Technician

Less often, the control board itself fails to drive or read the lock.

Check it: If the lock and wiring test good, a tech looks at the control.

Is it worth fixing?

Repair — a lid-lock assembly is an affordable, common part plus flat labor, far below a new washer. F5E2 is a very fixable code.

Common questions

How do I fix the F5E2 code on my Whirlpool washer?

First make sure the lid closes fully with nothing blocking it, and try a power reset (unplug for a minute). If F5E2 comes back, the lid-lock assembly is usually failing — an affordable, common tech replacement.

Why won't my Whirlpool washer start with an F5E2 code?

A top-load washer won't run until it confirms the lid is locked. F5E2 means it can't lock (or can't confirm the lock), so the cycle never begins — usually the lid-lock assembly.
