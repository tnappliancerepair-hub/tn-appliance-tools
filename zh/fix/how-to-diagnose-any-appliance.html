如何诊断任何电器：电源 → 开关 → 负载

真正技师的秘诀：不是背下一千种维修 —— 而是学会一个方法。通断和电压能解决约 95% 的故障，因为几乎每个故障都是一个简单电路里的一个断点：电源 → 开关/控制 → 负载。找出这三者中哪个测试不通过，就找到了要修的地方。

⚠ 安全第一：做通断/电阻测试时电器要拔掉电源。电压测试要带电进行，务必小心。绝不要触碰微波炉的高压电容 —— 即使拔了电也可能带致命电荷。注意 240V，燃气另作处理。

两项测试几乎搞定一切

电压："电有没有到这里？"—— 带电测量（交流电压）。  通断："这条路径或这个零件通不通？"—— 断电测量（欧姆 / 蜂鸣模式）。掌握这两项和一只 $15 的万用表，几乎任何问题都能追到确切的零件。

⚠ 电阻和通断 = 断电，并把零件的一端线拆下，否则你会读到整条电路（"绕路"）而被误导。电压 = 带电，小心。绝不要给带电电路测电阻。

每台电器都是同一个三段电路

不管什么机器，电必须依次经过三样东西。任何一环断了，机器就停。你的全部工作就是找出断掉的那一环。

1 · 电源

进来的电 —— 插座、电线、插头、断路器。

例：120V 插座、电线、断路器。电烘干机、电灶、电烤箱用 240V（两路）—— 断一路机器就"半死"（滚筒转，不加热）。

2 · 开关 / 控制

按条件接通或断开电路的"守门员"。

例：门开关/盖开关、温控器、热熔断丝、定时器、继电器、控制板。只有条件满足时才放行电流。

3 · 负载

消耗电、真正干活的零件。

例：加热元件、电机、水泵、阀门线圈、压缩机、点火器。负载多数断路损坏 —— 通断一测便知。

方法 —— 按此顺序测

1

电到了吗？（电压）

确认插座和电线送出应有的电压 —— 大多 120V，烘干机/灶具/烤箱 240V。这里没电 = 是插座、电线或断路器，不是电器本身。

2

开关放行了吗？（通断）

断电后测各开关和控制：门/盖开关、温控器、热熔断丝在闭合时应通（~0 Ω），松开时断开。若始终不通，这个守门员就是故障。

3

负载好吗？（通断）

断电后测负载 —— 加热元件、电机绕组、水泵、阀门线圈。好的负载读出其特征电阻；断路（OL）= 损坏，更换。

就这样。电进来 → 守门员放行 → 负载干活。哪一步测试不通过，那就是要修的地方。

读数含义（速查表）

~0 Ω / 蜂鸣通路良好 —— 路径/开关闭合且完好。
OL / 无穷大断路 —— 路径断了或负载坏了。通常就是坏件。
有 120V / 240V电已到达该点。
该有电却是 0V电没到 —— 往上游查（断路器、电线、未闭合的开关）。

"好负载"的典型电阻

烘干机加热元件~10–50 Ω（断路 = 烧坏）
烤箱加热元件~15–40 Ω（断路 = 烧坏）

热熔断丝/温控器（闭合）~0 Ω / 通（断路 = 熔断）
烤箱温度传感器室温约 1,080–1,100 Ω

具体数值因型号而异 —— 你要看的是"在范围内，还是完全断路？"。断路几乎总是最明确的信号。

哪些情况不适用电源-开关-负载

该方法覆盖约 95% 的电气故障。例外：密封系统/制冷剂（压缩机、泄漏 —— 仅限持牌并具 EPA 资质的技师）、机械问题（轴承、皮带、卡住的叶轮 —— 靠看和摸）、以及燃气（点火器是可测的负载，但燃气侧需专业人员）。还有微波炉高压电容 —— 即使断电也危险。

常见问题

技师为什么诊断得这么快？

他们用一个方法，而不是背一千种维修：查电源 → 开关/控制 → 负载，用电压和通断。哪个测试不通过，就是要修的。

电压和通断，用哪个？

电压（带电）回答"这里有没有电？"；通断（断电）回答"这条路径/零件通不通？"。

万用表上的 OL 是什么意思？

OL（超量程/无穷大）在通断测试里表示"断路"—— 路径断了或负载坏了。测加热元件或电机时，OL = 更换。

我该买什么万用表？

任何带通断（蜂鸣）、欧姆（Ω）和交流电压的便宜数字万用表都够用。

什么时候该找专业人员？

密封系统/制冷剂、燃气侧，以及一切涉及微波炉电容的情况。拿不准就发视频给我们。
