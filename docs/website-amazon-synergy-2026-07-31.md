# Website ⇄ Amazon — every beneficial relationship + how to maximize it (2026-07-31)

Our assets: **~2,000-page website** (7 languages, /fix authority pages, brand×appliance +
symptom + city pages, 1,081 Google reviews, email/SMS base, Ant repair data) **+ an Amazon
storefront** (curated SKUs, drop-ship spine, the write-once content generator). Goal: wring out
every synergy. Grouped by direction.

## HARD TRUTH FIRST (so we don't chase myths)
- **Amazon links are nofollow** → the Amazon store passes NO backlink/PageRank to our site.
  Don't expect Amazon to "SEO" our pages via links. Every benefit below is real WITHOUT that.
- **Amazon owns the Amazon customer** (limited data) → we reclaim them via the QR/insert.
- **No cannibalization:** website = local service + drop-ship long tail; Amazon = fat-head
  universal SKUs. Two buttons, two paths — they feed each other.

## A. WEBSITE → AMAZON (drive rank, sales, cash)
1. **External traffic → higher Amazon rank.** Amazon rewards off-Amazon traffic with better
   organic rank. Our 2,000 pages are that engine. **Max:** add a "Buy this part" module to the
   pages that actually rank (GSC-driven ~50 first, then /fix + brand×appliance) linking to the
   matching Amazon SKU.
2. **Brand Referral Bonus (~10% cash back).** Amazon pays ~10% of sales we drive from our site.
   **Max:** tag every website→Amazon link with **Amazon Attribution** so we capture the bonus + rank credit.
3. **Amazon Attribution analytics.** See which pages/keywords drive Amazon sales → double down.
   **Max:** Attribution tags everywhere; feed winners back into SEO priorities.
4. **Launch velocity.** New SKU → blast our top pages + email/SMS at it in the first-48h window
   (Amazon rewards early sales + reviews). **Max:** a launch playbook per SKU.
5. **Owned audience → Amazon.** Email/SMS base + site visitors → seed Sponsored Brands / DSP
   custom audiences later. **Max:** grow the list via the QR/insert loop (see B7).

## B. AMAZON → WEBSITE (brand, capture, data)
6. **Double SERP real estate.** Amazon listings rank in Google on Amazon's authority — so for a
   buy query BOTH our page AND our Amazon listing can appear. **Max:** identical brand naming so
   we own two slots, not one.
7. **QR-in-box + inserts → pull Amazon buyers to our site** (fix guide → fits.html, review, book
   service, buy more parts). Converts a one-time Amazon buyer into our OWNED audience + a local
   lead. **Max:** every box ships the QR; QR → confirm-fit / review / booking.
8. **Amazon buyers → local service funnel.** A parts buyer in TN/LA → offer install/service (our
   real margin). **Max:** insert + QR detect service-area ZIPs → "want us to install it?"
9. **Amazon reviews → site trust.** Show Amazon rating/count as trust badges (like we do Google).
   **Max:** cross-display Google + Amazon review counts on both surfaces.
10. **Amazon search-term data → website SEO.** What people type to BUY parts = high-intent
    keywords. **Max:** pipe Amazon search-term reports into the site keyword/content pipeline.

## C. SHARED SPINE (write once, rank/convert everywhere)
11. **Shared content engine (BUILT).** component-knowledge + fitment + symptoms/how-to-test →
    both /fix pages (Google) AND Amazon A+/listings (Amazon), EN+ES on Amazon, all 7 on site.
    **Max:** run every SKU through listing-studio → publish both sides from one source.
12. **Shared data moat.** Ant repair history + fitment feeds BOTH the site's diagnostic content
    AND Amazon fitment accuracy (fewer returns → higher Amazon rank). **Max:** keep capturing
    verified_part_number + return reasons; both surfaces get smarter.
13. **Unified brand + entity.** Same "real techs since 2012 / 1,081 reviews" story both places →
    branded searches ("TN Appliance parts") that surface both properties. **Max:** identical NAP,
    logo, story; Brand Store mirrors the site's identity.
14. **Reviews flywheel across both.** Site review-requests + Amazon "Request a Review" both grow;
    each raises trust that lifts the other. **Max:** run both review engines in parallel.

## THE COMPOUNDING FLYWHEEL (why it's more than the sum)
SEO pages → external traffic to Amazon → higher Amazon rank + ~10% referral bonus → sales →
reviews (Vine + insert + our base) → higher rank + more branded searches → more site traffic →
QR-in-box pulls buyers into our owned audience → fuels the next launch → repeat. AND every sale +
return reason trains fitment → fewer returns → higher rank + better site content. **The thing
that makes money deepens the moat.**
